# LK Multimidia | Stage plot lab

Isolated static prototype of the LK stage and venue plot editor. No authentication, no API requests, no real user data. GitHub branch lk-stageplot-preview-v1 only; production main and Vercel remain untouched.

## Included

- 17 generic equipment types, drag/drop and click-to-add
- Simple/Advanced editing, item quantity, L/R/C assignment
- Free placement, duplicate, delete, meter-scale grid
- Top edit view, illustrative front and lateral reference views
- Automatic unit counts, local-only persistence
- Import/export static JSON, browser print

## Not included

- Login, authenticated rider save, third-party manufacturer photographs, hosted images, commercial permissions or acoustic simulation
- Production rider schema integration, finalized PDF, responsive mobile acceptance testing

This is a functional early visual prototype and must not be deployed as an authenticated production site.
